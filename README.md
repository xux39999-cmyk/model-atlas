# Model Atlas · 免费 AI 模型查询器

无需安装、无需 API Key。双击 `dist/index.html` 即可本地使用。

## 第一次使用

1. 点击“编程”，再把“免费类型”切换为“有免费档”。
2. 点击“查看条件”，核对额度、地区和数据政策。
3. 点击“复制 ID”，或点星星收藏。实际调用模型需另行注册对应平台的 API Key。

## 当前能力

关键词搜索、用途筛选、免费类型筛选、条件详情、复制模型 ID、浏览器本地收藏、手机布局。

这是手动维护的目录，不实时抓取政策，不发送模型请求。资料核查日期为 2026 年 10 月 18 日；上线后的免费政策可能变化，请以官方页面和账号控制台为准。平台目录与具体模型不同，目录的用途标签表示可供寻找相关模型，不代表所有模型都有该能力。

## 文件分别是什么

- `dist/index.html`：页面内容和结构。
- `dist/style.css`：深色、灰紫色外观和手机布局。
- `dist/models-data.js`：独立的公开模型资料，每条记录含官方来源、免费政策分类和核查日期。
- `dist/app.js`：筛选、详情、复制和收藏逻辑。
- `scripts/check-data.cjs`：资料格式检查，不参与网页运行或 Netlify 发布。

## 以后如何维护资料

只更新 `dist/models-data.js` 中的相应记录。`checkedAt` 是这条资料实际核查的日期，不是改代码的日期；没有重新核查政策时，不要更新它。详情页显示该条资料的日期，顶部显示全部资料的核查日期或日期范围。

`type` 可取 `free`（有免费档）、`trial`（新人或限时试用）、`unknown`（付费或待确认，须结合具体说明阅读）。`source` 是支持资料的官方链接；未核实的条件继续明确写未确认。模型 ID 为空的记录是平台或厂商入口。

有 Node.js 时可运行 `node scripts/check-data.cjs`，检查重复标识、必填字段、来源链接、状态和日期。这个检查只验证格式，不证明政策真实或最新。

资料文件拆分本身不调用 AI API，也不改变原有模型政策。双击本地 HTML 仍可使用；Netlify 构建命令继续留空，发布目录仍为 `dist`。整个 `dist` 文件夹需要一起上传，包含新增的 `models-data.js`。

## 官方来源变化检查

下一阶段新增了 GitHub Actions 监测流程，启用步骤与边界请看 `monitoring/README.md`。它仅检测已有来源的网页变化并生成草稿审核 PR，不直接修改模型政策或替你完成事实核查。检查在 GitHub 上执行，不依赖本机每天开机。

没有浏览器存储权限时，收藏只保留在本次打开期间。复制权限不可用时，可从详情手动选中模型 ID 复制。外部字体加载失败时会使用系统字体。
