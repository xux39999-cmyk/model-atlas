# Model Atlas · 免费 AI 模型查询器

无需安装、无需 API Key。双击 `dist/index.html` 即可本地使用。

## 第一次使用

1. 点击“编程”，再把“免费类型”切换为“有免费档”。
2. 点击“查看条件”，核对额度、地区和数据政策。
3. 点击“复制 ID”，或点星星收藏。实际调用模型需另行注册对应平台的 API Key。

## 当前能力

关键词搜索、用途筛选、免费类型筛选、条件详情、复制模型 ID、浏览器本地收藏、手机布局。

这是手动维护的目录，不实时抓取政策，不发送模型请求。资料核查日期为 2026 年 10 月 18 日；上线后的免费政策可能变化，请以官方页面和账号控制台为准。平台目录与具体模型不同，目录的用途标签表示可供寻找相关模型，不代表所有模型都有该能力。

## 三个文件分别是什么

- `dist/index.html`：页面内容和结构。
- `dist/style.css`：深色、灰紫色外观和手机布局。
- `dist/app.js`：模型资料、筛选、详情、复制和收藏逻辑。

没有浏览器存储权限时，收藏只保留在本次打开期间。复制权限不可用时，可从详情手动选中模型 ID 复制。外部字体加载失败时会使用系统字体。
